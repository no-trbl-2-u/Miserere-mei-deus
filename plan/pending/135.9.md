## Notes
- **135.9 (SM2j) defaults.** `--shillings` takes any positive number and rounds each rise in the purse (a spend is left alone). `--boss-level` re-registers the start map's boss pool for the run and puts it back after, since the pool lookup itself is private to its module and cannot be wrapped. `--no-guard` subtracts the guard band from each ranking, so only guard cards in a hit turn move. `--no-relic-stats` without a `--start-relic` is refused. `--post` with any tuning flag, or with a policy list, exits non-zero before a run is played.
