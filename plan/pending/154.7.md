## Decisions
- **D?cache-action-lines** · 2026-11-06 · A cache carries its two action lines as data, one per choice, on the MapEvent payload: what you do to earn that side, never the reward. An unwritten cache carries `[content]` on both. *Why:* T's pattern for every cache, so the screen never has to be told what a node pays.
