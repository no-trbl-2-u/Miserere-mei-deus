UI kit: keep which look?

44 places the kit can go. For each, tick the one look to keep: Normal (as it is now), Brass Gothic, or Vellum & Ink.

Ticking another look in the same place moves the tick. Use the note box when it's "this one, but…" (a different piece, smaller, no frame, only on one screen).
Vellum is a preview: the vellum pieces swapped onto the brass build, text inked dark on parchment. It has no bars, rings, END button or toggles, so those stay brass.
The title screen's EMBARK is not on here: it stays as it is.
