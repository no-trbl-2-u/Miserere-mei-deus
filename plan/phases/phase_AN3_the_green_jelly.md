## Acceptance

- **A1 (the fight is preserved, not re-tuned)** Level, stat budget, `difficulty: 'elite'`,
  `logic: 'strategic'`, `mapName`, loot table, the befriend hp gate and `xpBonus: 35` are
  carried over unchanged. This phase changes identity and art, never balance. A test or the
  diff shows each numeric unchanged.
- **A2 (the id moves everywhere at once)** `enemy-brine-hag` and the art key `brine-hag`
  become the new id and key in *every* place they appear — the library, the enemy decks, the
  stage profiles, the mobile mock, every engine test and every doc. A repo-wide search for
  the old strings returns nothing outside provenance and plan history.
- **A3 (saves are considered, not assumed)** Whether a persisted save can carry an enemy id
  is established by reading the save schema, and the answer is recorded. If one can, the
  phase either migrates it or states why it cannot break a run. "No save reads it" is a
  finding to prove, not a default.
- **A4 (the prose is the creature's own)** The `description` and the `friendshipReward`
  narrative are rewritten for a gelatinous creature. They cannot be renamed around: the
  Hag's lines are about a traded reflection, a tide and keeping one's face, and reading them
  over a jelly would be worse than a placeholder. Drafted in the repo's existing voice for T
  to accept or replace at review.
- **A5 (the art lands with its provenance)** `Jelly A.png` is ingested to
  `assets/images/enemies/<newkey>.webp` through the existing `RECIPE` — it is a *new* source,
  never graded before, so it takes the full recipe, not `--no-grade`. Its provenance record
  carries the torio Javardry grant, the artist, the pack and the catalog slug. `Potential
  Assets/` stays a store and nothing resolves a path into it (D96, rule 9).
- **A6 (the frame set is installed and it animates)** The 8x3 / 24-cell sheet is generated by
  an `art-department/` rig, split to per-cell WebP, registered, and a test drives the
  encounter pane for the new key and asserts the frame player mounts and advances. The clips
  are `idle` / `struck` / `attacking`, the names `REQUIRED_CLIPS` already demands.
- **A7 (the anchor kind is `foot-line`, not `centre`)** Unlike the float-eye, a jelly SITS on
  a surface and its squash-and-stretch is about its base. A6's default kind is correct here
  and the manifest says so — this is the first set to exercise the other branch of that rule.
- **A8 (within the measured ceiling)** Every cell is under `FRAME_CELL_MAX_BYTES`, and the
  per-set cost is recorded beside the float-eye's 24 cells / 152.8 KB for comparison.

Measure: the A1 numeric diff; a repo-wide search clean of the old id; the A6 encounter test;
`npm run verify -w axiomancer-mobile` and root `npm test` green.

## Save / schema contracts

Open by A3. The phase must read the save schema and record what it finds before deciding.

**Answer (AN3a, 2026-10-22).** A save is `durableSlice` in `Game/store.ts`: version, runId,
player, world, quests, flags, rngState, codex and the labyrinth. The staged encounter is never
written, and map state holds no payloads, so no save names the Hag's enemy id or art key. The
Hag is befriendable, though, and her friendship writes two ids that do persist: the
`befriended-brine-hag` flag and the `codex-brine-hag` codex entry. Both are renamed, so the
migration is needed: `GAME_STATE_VERSION` 37 to 38, hop `migrateV37ToV38` in
`Game/game.migrate.ts`, pinned by `Game/e2e/green-jelly-rename-migration.engine.test.ts`.
Without it a befriended Hag's codex entry would no longer resolve.

## Decisions made upfront — DO NOT ASK

- **T chose the art, attended, 2026-10-22**, after being shown the rigged sheet: "Green
  Jelly? Yes, 100%! Replace the hag with him." That is the owner approval D37/D88 requires
  for art; the loop is installing a choice T made, not making one.
- **The licence is settled.** The catalog records the torio Javardry grant as free for any
  use including commercial, modification and redistribution, no attribution required. The
  same grant covers the float-eye, whose provenance still reads UNRESOLVED and should be
  corrected (follow-up below).
- **Replace, do not add.** T asked for the Hag to become the Jelly. Adding a fourth enemy
  would change encounter pacing; renaming preserves it.
- **`foot-line`, not `centre`** (A7). The float-eye floats and its hover is the animation; a
  jelly rests on a surface and squashes about its base. Anchoring it centrally would make it
  bob while it squashed.
- **Full `RECIPE`, not `--no-grade`** (A5). A6b's rule is grade exactly once in an asset's
  life; this source has never been graded, unlike the derived float-eye cells.
- **The rig needs no masks.** The jelly is a single volume: scale about a base pivot, wider
  being shorter. That is why it rigs cleanly where the Hag's four limb masks still showed a
  seam, and why T picked it.
