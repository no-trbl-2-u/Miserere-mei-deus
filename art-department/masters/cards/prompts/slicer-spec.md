# Slicer spec: sheets into card paintings

Not built yet. This is what the script must do once the sheets are in `../card-images/<lane>/`.

## Input

- `card-images/<lane>/sheet-<n>.png`: a ChatGPT sheet, 3 x 2 tiles divided by magenta (#FF00FF) gutters and border.
- `card-images/<lane>/manifest.json`: for each sheet, the card id in each tile, left to right then top to bottom;
  `null` for an empty tile.

## What it does

1. **Find the gutters.** A gutter is a full row or column whose pixels are near magenta (each of R and B above 200,
   G below 60, to allow for JPEG-like noise in the export). Take the runs of gutter rows and columns; the gaps
   between them are the tiles.
2. **Refuse a bad sheet, loudly.** Stop with a message naming the file if it finds anything other than 3 columns
   by 2 rows, if any tile is more than 4% off square, or if any tile is under 400 px. Never guess a grid.
3. **Trim and clean each tile.** Cut 3 px inside each edge so no magenta fringe survives, then check the cut tile
   has no near-magenta pixel left; if it does, refuse it.
4. **Check the background.** The outer 5% ring of each tile should be near black (mean under 20 of 255). Warn,
   with the card id, when it is not: that painting broke the black-background rule.
5. **Write the painting.** Resize to 640 x 640 (Lanczos) and save as WebP at quality 44, the repo's ingest recipe
   (`scripts/ingest-art.mjs`, `scripts/shrink-art.mjs`), named `<card id>.webp`, into a review folder
   `card-images/<lane>/cut/`.
6. **Make a contact sheet.** `card-images/<lane>/cut/contact.png`: every cut painting, labelled with its card name,
   beside four Blood Price paintings, so the lane can be judged against the shipped style at a glance.

## Into the game (later, as a loop phase)

- Copy the reviewed WebPs to `axiomancer-mobile/assets/images/cards/` and register each id in
  `assets/images/cards/index.ts`.
- Add a `provenance.json` entry: generated by ChatGPT from these prompts, the date, and the prompt files.
- Extend `assets/images/cards/__tests__/card-art.test.ts` so every Defender, Elementalist and Merciful card has
  its own painting, not the fallback, as Blood Price already does.
- Before/after screenshots of a hand of each lane, next to a Blood Price hand.

## What proves it worked

- The slicer finds exactly six tiles on every full sheet and the right count on the last one, and refuses nothing.
- The test above passes: every lane card has its own painting.
- The screenshots read as one game with Blood Price, and T plays them on the phone.
